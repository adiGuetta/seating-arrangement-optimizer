Features

🌳 Hierarchical Guest Tree

Organize guests into a tree structure with as many levels as you need. Top-level groups like "Bride's Side" and "Groom's Side" can contain subgroups for families, friend circles, coworkers, and more. The tree structure tells the solver who should sit near whom — guests closer in the tree are more likely to share a table.

  • Create groups and nest them to any depth
  • Add guests to any group — leaf or internal
  • All guests within the same group are always seated together (they're treated as an atomic unit by the solver)
  • You can have multiple root-level groups — the solver handles them automatically
💡 Tip: If you want individual guests to be independently assignable to different tables, put each one in their own group.

🔀 Moving Groups in the Tree

Restructure your guest tree at any time. There are two ways to move a group to a different parent:

  • Tree View (visual): Open the tree view, then long-press a node to start moving it. Valid drop targets will highlight with a dashed border and an arrow icon. Tap the destination node to complete the move. The group and all its subgroups move together. Tap "Cancel" to abort.
  • Edit Group: Open any group, tap "Edit Group", and use the parent picker to select a new parent — including "None (top-level)" to make it a root group.
  • List View: In the event's group list, tap the drag handle (≡) on a group to start moving, then tap the target group.
💡 Tip: You can't move a group into its own subtree — the app prevents circular references.

⚖️ Group Distance Weights

Control how "far apart" branches of your tree are in the solver's eyes. The weight on each group's edge determines how strongly it separates that branch from its parent.

  • Higher weight (e.g. 5) = guests in this branch are less likely to share a table with people outside it. Use this for major divisions like Bride's Side vs. Groom's Side.
  • Lower weight (e.g. 0.5) = more mixing allowed. Use this for closely related sub-families you don't mind sitting together.
  • Default is 1 — every edge counts equally, like a simple hop count.

Set the weight when creating or editing a group. The tree view shows weights on edges where they differ from 1.

🧬 AI-Powered Seating Solver

When you tap "Generate Seating", the app sends your guest tree to an evolutionary optimization solver (NSGA-II) enhanced with a Graph Neural Network. The solver minimizes two objectives simultaneously:

  • Number of tables — fewer is better
  • Seating penalty — a combination of guest loneliness (being far from family at your table) and family separation (related people split across tables)

The result is a set of Pareto-optimal solutions — each one is the best possible arrangement for a given number of tables. You choose the trade-off that works for you.

💡 Tip: The solver typically takes 30–60 seconds. A spinner shows while it's working. If the solver is unavailable, the app falls back to random seating.

🎛️ Tuning Parameters

Before generating, you can adjust three parameters that influence the solver:

  • Max Table Size: The maximum number of guests per table (4–20). The solver will never exceed this.
  • Keep Families Together (α): How strongly to penalize lonely guests. Higher values mean the solver tries harder to keep related people at the same table. Default: 2.0.
  • Avoid Lonely Guests (p): The exponent on the loneliness penalty. Higher values punish extreme isolation more harshly — a single person sitting alone is penalized much more than two people from the same family. Default: 2.0.

🔄 Compare & Save Candidates

The solver returns multiple candidate arrangements, each with a different number of tables. For each candidate you can see:

  • Total number of tables and guests
  • Average coherency score across all tables
  • Detailed per-table breakdown with visual table circles

Tap any candidate to preview it in full detail. Tap the save icon to keep it as a saved arrangement. Discard all unsaved candidates when you're done.

✋ Manual Adjustments

After generating and saving an arrangement, fine-tune it by moving individual guests between tables:

  • Tap a guest to select them — they'll be highlighted
  • Tap the destination table (either the circle or the list header) to move them there
  • Metrics update in real-time so you can see the impact of every move
  • Tap the selected guest again to deselect

Use the search bar to quickly find a guest by name across all tables.

📊 Per-Table Metrics

Every table displays two key metrics to help you evaluate the arrangement:

  • Coherency (C): What fraction of the table comes from the same group. Green (≥70%) = great, yellow (40–70%) = okay, red (<40%) = very mixed.
  • Loneliness (L): The size of the smallest group at the table. Red (1) = someone is sitting alone, yellow (2) = a pair, green (3+) = comfortable.

A ⚠ warning highlights the globally loneliest group across all tables. Sort tables by coherency, loneliness, or guest count using the sort bar.

👤 Guest Hierarchy in Arrangements

Every guest in a seating arrangement shows their full path in the tree — for example, "Our Event › Bride's Side › Mom's Side". This makes it easy to distinguish guests with the same name who belong to different branches of the family.

🔍 Subtree View

Want to see where just one branch of the family ended up? The subtree view lets you:

  • Pick any group as the subtree root (e.g. "Bride's Family")
  • Pick any saved arrangement
  • See only the tables that contain guests from that branch

Guests from outside the subtree are shown dimmed with an "outside subtree" label, so you can see who else is at those tables for context.

📋 Multiple Events

Planning more than one event? The app supports multiple independent events, each with its own guest tree, seating config, and saved arrangements.

  • Create a new event from scratch
  • Clone an existing event to use it as a starting point (all groups and guests are deep-copied with new IDs)
  • Export a subtree from one event into another — useful when a subset of guests attends a different event

Tap the event name or stats to open it. Use the pencil icon to rename or change the date, and the trash icon to delete.

🌐 Bilingual (English & Hebrew)

The entire app is available in English and Hebrew with full RTL support. Tap the language toggle in the top bar to switch instantly. All labels, hints, button text, and layout direction adapt immediately — no reload needed.

🌙 Dark Mode

Toggle between light and dark themes using the sun/moon icon in the top bar. Your preference is remembered across sessions.

☁️ Cloud Sync & Offline

You can use the app in two modes:

  • Signed in (Google): Your events are synced to Firebase and accessible from any device. Changes save automatically.
  • Offline / Guest mode: Skip login and work locally. Data is saved to your browser's local storage. You can sign in later to sync.

Under the Hood: The Solver

The seating optimizer is a multi-objective evolutionary algorithm that treats your guest tree as a real mathematical structure.

🌲 Weighted Tree Distance

Guests are compared by their weighted distance in the family tree. Each edge's weight (set by you) determines how "far apart" two branches are. The solver uses an Euler-tour LCA structure for O(1) distance queries between any two groups.

🧬 NSGA-II Optimization

A population of 100 candidate seatings evolves over 250 generations using crossover and mutation operators. Two objectives are optimized simultaneously: minimize table count and minimize a penalty combining loneliness and family separation.

🧠 GNN Initialization

A Graph Neural Network, pre-trained on thousands of synthetic guest trees, provides smart starting arrangements. Each node's features include tree depth, group size, and subtree population fraction. This gives the evolutionary optimizer a significant head start.

📐 Pareto Front

Instead of one "best" answer, you get the full Pareto front — every optimal trade-off between table count and seating quality. Each solution is the best possible arrangement for its number of tables.
